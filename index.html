Политика конфиденциальности

Faberlic Forever

Дата редакции: 24 октября 2026 года

Настоящая Политика конфиденциальности описывает порядок обработки и защиты данных пользователей обучающего приложения Faberlic Forever для устройств Android и iOS.

1. Владелец приложения

Владелец и ответственное лицо: Алишер Хафизов.

2. Назначение приложения

Faberlic Forever — закрытое обучающее приложение, предназначенное для внутреннего использования участниками команды Faberlic Forever.

Приложение создано для обучения консультантов и руководителей команды, повышения профессиональных знаний, просмотра обучающих видеоматериалов, эфиров и изучения информационных материалов.

Доступ к обучению предоставляется исключительно по индивидуальному приглашению руководителя команды.

Приложение не предназначено для свободного использования неограниченным кругом лиц.

Для получения доступа пользователь проходит активацию с помощью специального кода приглашения.

3. Какие данные обрабатываются

Для предоставления доступа и обеспечения работы приложения могут обрабатываться:

  • Код приглашения, введённый пользователем.
  • Случайный идентификатор установки приложения для проверки активации.
  • Статус и дата активации.
  • Тип операционной системы: Android или iOS.
  • Технические данные сетевых запросов, необходимые для подключения к используемым сервисам.

Если администратор указывает имя получателя приглашения в системе управления доступом, эти сведения могут использоваться для учёта выданных приглашений и поддержки пользователей.

4. Данные на устройстве

Приложение может сохранять на устройстве:

  • Выбранный язык интерфейса.
  • Список избранных материалов.
  • Пользовательские настройки.
  • Информацию, необходимую для сохранения активированного доступа.

Эти данные используются для удобства пользователя и правильной работы приложения.

5. Цели обработки данных

Информация используется исключительно для целей, связанных с работой приложения:

  • Проверка права пользователя на доступ к обучению.
  • Предотвращение повторного использования одноразовых кодов приглашения.
  • Сохранение активированного состояния.
  • Предоставление обучающих материалов.
  • Обеспечение технической работоспособности и безопасности.
  • Рассмотрение обращений пользователей.

6. Сторонние сервисы

Для работы приложения используются сторонние технологические сервисы.

Google Firebase используется для получения данных об обучающих материалах и может применяться для управления доступом.

YouTube используется для воспроизведения обучающих видео. При просмотре видео Google может обрабатывать техническую информацию в соответствии со своими правилами.

Дополнительная информация:

  • Политика конфиденциальности Google
  • Конфиденциальность Firebase

Данные, обрабатываемые сторонними сервисами, могут передаваться на серверы за пределами страны проживания пользователя.

7. Передача и защита данных

Владелец приложения не продаёт персональные данные пользователей.

Данные могут передаваться поставщикам технических услуг в объёме, необходимом для функционирования приложения, либо в случаях, предусмотренных законодательством.

Для защиты данных применяются организационные и технические меры, направленные на предотвращение несанкционированного доступа.

При этом абсолютная безопасность хранения и передачи информации не может быть гарантирована.

8. Срок хранения данных

Информация об активации хранится, пока она необходима для управления доступом, предотвращения повторных активаций и обеспечения безопасности.

Данные удаляются после прекращения необходимости в их обработке или по подтверждённому обращению пользователя, если их дальнейшее хранение не требуется по закону.

Локальные настройки и избранное могут быть удалены при очистке данных приложения или его удалении с устройства.

9. Права пользователя

Пользователь вправе обратиться к владельцу приложения для:

  • Получения информации об обработке своих данных.
  • Уточнения неточных сведений.
  • Запроса удаления данных, связанных с активацией.
  • Прекращения доступа к приложению.

Запрос направляется по электронной почте, указанной в разделе «Контактная информация».

Для защиты данных владелец может запросить подтверждение принадлежности активации заявителю.

10. Изменения политики

Политика может обновляться при изменении функций приложения, используемых сервисов или порядка обработки данных.

Актуальная редакция размещается на этой странице с указанием даты.
